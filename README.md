# Lendas do Oriente

RPG 3D de fantasia oriental desenvolvido em Unity e C#, com foco inicial em Android.

## Visão
Criar uma experiência própria inspirada na sensação dos MMORPGs orientais clássicos, sem copiar mapas, personagens, nomes, modelos, texturas, músicas ou código de outros jogos.

## Primeira região: Vila das Cerejeiras
O primeiro protótipo jogável terá:
- Portão Principal
- Ponte do Lótus
- Praça Central
- Templo da Harmonia
- Ferreiro
- Comerciante
- Mestre de Habilidades
- Casa de Missões
- saída para a Floresta de Bambu

## Marco 0.1 — Protótipo Android
1. Cena 3D simplificada da Vila das Cerejeiras
2. Personagem provisório em terceira pessoa
3. Movimento e câmera
4. Controles mobile
5. HUD básico
6. Primeiro NPC
7. Primeiro inimigo
8. Build APK para teste

## Arquitetura
A lógica será organizada por domínio para manter baixo acoplamento entre jogador, combate, NPCs, missões, inventário e interface.

## Performance mobile
O projeto será desenvolvido desde o início pensando em Android: LOD, object pooling, iluminação otimizada, texturas comprimidas, carregamento controlado e redução de draw calls.

## Idioma
Documentação, nomes dos sistemas do projeto e comentários serão mantidos em português sempre que tecnicamente apropriado.
